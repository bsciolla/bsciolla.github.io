# Bruno's Website (Eleventy)

Migrated from Jekyll to Eleventy.

## Setup

```bash
npm install
```

## Development

```bash
npm start
```

## Build

```bash
npm run build
```

## Structure

- `_includes/` - Layout templates (Nunjucks)
- `posts/` - Blog posts
- `_site/` - Build output (gitignored)
- `demo.html` - Untouched game page
